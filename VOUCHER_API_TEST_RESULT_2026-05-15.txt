Voucher API test result
Date: 2026-05-15

Swagger UI opened:
http://127.0.0.1:9090/swagger-ui/index.html

Summary
- Tested voucher creation through backend voucher APIs.
- Direct typed voucher create route failed:
  - POST /api/vouchers/journal?action=Create
  - Result: 502
  - Tally error: "Voucher date is missing for: 'Journal' voucher 9015."
- Working voucher route:
  - POST /api/vouchers/import-xml
  - Result: 200
  - Tally import acknowledgement: CREATED=1

Important finding
- In this environment, the generic/type-specific JSON voucher create routes are still not reliable for create.
- The voucher XML import route is the one that successfully created a voucher against Tally.
- The successful create used the existing company accounting date 20260402 instead of 20260515.
